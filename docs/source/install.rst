Installation
============

PyBroker supports Python 3.9+ on Windows, Mac, and Linux. You can install
PyBroker using ``pip``:

.. code-block:: console

    pip install -U lib-pybroker

To use the optional `AKShare` data source for Chinese market data, install
akshare separately:

.. code-block:: console

    pip install 'akshare>=1.17.50'

Or you can clone the Git repository with:

.. code-block:: console

    git clone https://github.com/edtechre/pybroker
